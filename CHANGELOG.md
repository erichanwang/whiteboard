# Changelog

## 0.1.0 - 2026-07-20

- Native Tauri whiteboard with mouse, touch, and stylus drawing
- Whiteboard and blackboard themes with an optional grid
- Cursor-centered wheel and pinch zoom, middle-drag pan, and right-drag selection
- Move and uniformly resize selected strokes, text, LaTeX, and images
- Mouse-wheel tool cycling in the bottom tool group
- Multiple persistent left, middle, and right mouse-button key substitutes
- Full-canvas cursor lock with accelerated movement, toggled with `M`; hold left click to draw
- Persisted theme, grid, drawing tool, ink color, and pen width defaults for new boards
- In-app text and LaTeX editors, embedded images, undo/redo controls, selection deletion, visible-area or entire-board clearing, native JSON files, PNG export, and private autosave
- Native Board Library with date-time board names
- Guided handwriting samples and NVIDIA-powered text/LaTeX recognition
- Visible-area, selected-ink, and entire-board recognition scopes
- Editable recognition corrections that inform later requests
- Positive recognition feedback, recognized-area highlighting, and an experimental lowercase handwriting renderer after five guided samples per letter
- MIT license
